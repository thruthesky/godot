# 2. 1단계 — 씬 만들고 저장

> **[예제 — 빈 프로젝트에서 캐릭터가 움직이기까지](../example.md)** 의 파트 **3 / 14**
> [← 1. 완성 모습과 씬 구조](01-scene-structure.md) · [3. 2단계 — 환경 (태양은 만들지 않는다) →](03-step2-environment.md)


## 조작

1. `Scene > New Scene`
2. 화면 오른쪽에 뜨는 **`3D Scene`** 을 클릭한다 → 루트 `Node3D` 가 생긴다
3. 루트를 선택하고 **F2** → 이름을 `Main` 으로 바꾼다
4. **Cmd+S**(Windows·Linux 는 Ctrl+S) → `res://scenes/main.tscn` 으로 저장
   (폴더 이름은 이 프로젝트 규범대로 **`scenes/`** — SKILL.md 파일 배치 규범. 예전 판의 `scene/` 로 이미 만들었다면 폴더 이름만 바꾸면 된다)
   - 폴더가 없으면 저장 대화상자 안에서 만들 수 있다

## 왜 `3D Scene` 인가

**씬의 타입은 루트 노드가 정한다.** 나중에 `Change Type...` 으로 바꿀 수는 있지만(§9 에서 실제로 쓴다) 스크립트의 `extends`·프로퍼티·자식 호환이 깨질 수 있으므로 **처음에 맞게 고른다.**
`Node3D` 로 시작하면 3D 씬이 되고, `Control` 로 시작하면 UI 씬이 된다.
`2D Scene` 을 눌렀다면 지우고 다시 만든다.

## 저장하지 않으면

씬 파일이 없으면 메인 씬으로 지정할 수 없고, 다른 씬에서 인스턴스로 쓸 수도 없다.
**Godot 에서 "만든다"는 것은 곧 "`.tscn` 파일로 저장한다"는 뜻이다.**
